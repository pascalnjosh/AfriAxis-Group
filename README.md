# AfriAxis ERP

AfriAxis ERP is a Django-based enterprise resource planning system.

## V1 Production Release

Core modules:
- Rentals and tenants
- Billing and payments
- Accounting and General Ledger
- Banking reconciliation
- Sales
- Purchasing
- Inventory
- Manufacturing
- Executive dashboards
- Role-based access

## Technology

- Python 3.11
- Django 5.2
- PostgreSQL production database
- SQLite local database
- Gunicorn
- WhiteNoise
- Render

## Run Locally

python manage.py check
python manage.py migrate
python manage.py runserver

## Status

AfriAxis ERP V1 is operational and ready for production deployment.
